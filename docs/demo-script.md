# Three-minute demo script

## 0:00–0:25 — the promise

Open Home.

> “In an emergency you get one voice. Ek Awaaz turns it into many calls and a calm guide. The call is the interface; this screen is mission control.”

Point out the permanent demo banner and test-number notice.

## 0:25–1:20 — shared understanding

Open Live Console and choose **Run demo**.

> Caller: “Bike ka accident hua hai, do log injured hain.”

> Caller: “Baner flyover ke baad, blue temple ke paas.”

Point to the highlighted transcript and incident card filling in. The same pipeline handles simulator and Bolna input.

For the live-phone version, choose **Call me live**, answer the configured phone,
and speak the same scenario. Bolna returns the completed call transcript to this
console; the app then extracts and displays the incident through the same pipeline.

For the no-voice path, clear the session and choose **Simulate spike** beside
**I cannot speak**. Capture the browser location or type a landmark, confirm the
address, record the 10-second scene clip, and submit. The incident card and
simulated coordination timeline update without placing a voice call. Explain that
real device motion monitoring requires browser permission and builds a rolling
baseline while the page is open; a motion spike alone never triggers dispatch.

## 1:20–1:50 — correction and confirmation

The scripted caller corrects the address:

> “Nahi, actually tunnel ke dusri side…”

Show the location update and confirmation reset. Then:

> “Haan, sahi hai.”

No action begins before confirmation.

## 1:50–2:25 — parallel action

Point to the timeline as tailored ambulance, police, family, and location-link actions progress independently. Real mode permits only configured stand-in numbers, retries once, and rate-limits calls.

Press **Stop all actions** to demonstrate the kill switch, or let the simulation finish.

## 2:25–2:45 — silent mode

Clear the session, then choose **Silent demo**.

> “The phrase ‘I’d like to order the usual’ moves the Listener into quiet yes-or-no and keypad interaction. It never speaks the address aloud.”

## 2:45–3:00 — report

Open Reports, select the completed incident, and export the PDF.

> “The record is timestamped, printable, and session-scoped. One frightened voice becomes calm understanding, confirmed action, and an accountable report.”
